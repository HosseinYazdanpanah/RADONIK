# RADONIK | وب‌سایت مستقل پرتو نگار شهاب

پروژهٔ مستقل شرکتی، آموزش و کاتالوگ رادونیک بر پایهٔ **Next.js App Router**، **React** و **Neon PostgreSQL**.

## امکانات
- رابط واکنش‌گرای فارسی RTL، برند و لوگوی رسمی رادونیک.
- کاتالوگ، جستجو، صفحات محصول و ثبت استعلام مستقیم در دیتابیس.
- شبکه‌های اجتماعی تأییدشده، نوار Hover شناور، پشتیبانی با ثبت پیام.
- پنل اپراتور و درخواست‌های خرید در `/support/dashboard` با نشست امضاشده.
- بدون لینک خرید، ورود یا مقاله به WordPress سابق؛ تصاویر محلی.

## راه‌اندازی
```bash
npm install
npm run dev
```
برای پشتیبانی به `.env.support.example` و [راهنمای پشتیبانی](docs/SUPPORT-OPERATIONS.md) مراجعه کنید. اطلاعات واقعی رمز عبور و اتصال دیتابیس را فقط در تنظیمات امن نگه دارید.

**نکته مهم:** قیمت‌ها باید هنگام خرید تأیید شوند. پرداخت مستقل آنلاین هنوز فعال نیست؛ ثبت درخواست و استعلام فعال است. برای بهره‌برداری عمومی سیاست حفظ حریم خصوصی و ضداسپم اضافه شود.
